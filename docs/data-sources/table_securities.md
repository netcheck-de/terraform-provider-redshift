# redshift_table_securities (Data Source)

Lists whether row-level security is on, the conjunction type, and the datashare setting for the relations of one
database that `svv_rls_relation` reports. See AWS
[SVV_RLS_RELATION](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_RLS_RELATION.html).

## Example Usage

```terraform
data "redshift_table_securities" "sales" {
  database = "analytics"
  schema   = "sales"
}

output "rls_protected_relations" {
  value = [for relation in data.redshift_table_securities.sales.table_securities : relation.relation if relation.row_level_security]
}
```

```sql
-- List the row-level security settings of the selected database, optionally of one schema.
SELECT ... FROM svv_rls_relation WHERE datname = 'database' AND relschema = 'schema';
```

## Read Behavior

AWS documents `svv_rls_relation` as listing the RLS-protected relations, not every table and view. A relation the
view does not report is absent from this list, while `redshift_table_security` reports the defaults for it: row-level
security off, `AND`, and on for datashares. Items are ordered by schema and relation. Superusers see every relation;
other users see only their own. `id` contains the target database and configured filters within the warehouse.
