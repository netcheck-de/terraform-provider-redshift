# redshift_copy_job (Data Source)

Reads whether a copy job loads files automatically and which IAM role its COPY command uses. See AWS
[SYS_COPY_JOB](https://docs.aws.amazon.com/redshift/latest/dg/SYS_COPY_JOB.html).

## Catalog Query

```sql
SELECT ... FROM sys_copy_job WHERE job_name = '...';
```

## Example Usage

```terraform
data "redshift_copy_job" "events" {
  database = "analytics"
  name     = "events_auto_load"
}

output "events_job_auto" {
  value = data.redshift_copy_job.events.auto
}
```

## Schema

### Required

### Read-Only

- `auto` (Boolean) Whether Redshift loads new files automatically (`AUTO ON`).
- `format` (String) Data format of the COPY command. Not readable from the catalog, so the lookup reports null.
- `format_argument` (String) Argument of the format. Not readable from the catalog, so the lookup reports null.
- `iam_role` (String) IAM role ARN the job's COPY command uses, as `SYS_COPY_JOB` reports it.

- `parameters` (Map of String) COPY parameters of the job. Not readable from the catalog, so the lookup reports null.
- `source` (String) Amazon S3 prefix the job monitors. Not readable from the catalog, so the lookup reports null.

`id` (String, computed) is the job's JSON identity, using the paired resource's warehouse, `database`, and `name` keys.
