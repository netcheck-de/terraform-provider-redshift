# redshift_identity_providers (Data Source)

Lists every SQL identity provider of type `AWSIDC` or `AZURE` with the details that
[SVV_IDENTITY_PROVIDERS](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_IDENTITY_PROVIDERS.html) reports. Only
superusers can read them.

## Example Usage

```terraform
data "redshift_identity_providers" "all" {}

output "enabled_identity_namespaces" {
  value = [for provider in data.redshift_identity_providers.all.identity_providers : provider.namespace if provider.enabled]
}
```

## Read Behavior

Items are ordered by name. A provider with an unsupported type or malformed catalog parameters is an error, as in
`redshift_identity_provider`. The client secret, `auto_create_roles`, and its group filters are not in the catalog and
are not listed. Values match what `redshift_identity_provider` reports for each provider. `id` identifies the listing
within the configured warehouse.
