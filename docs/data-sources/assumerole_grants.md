# redshift_assumerole_grants (Data Source)

Lists `ASSUMEROLE` grants, one element per IAM role and grantee, without taking ownership. Each element matches the
identity and privileges of one `redshift_assumerole_grant`. See AWS
[SVV_IAM_PRIVILEGES](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_IAM_PRIVILEGES.html).

## Example Usage

```terraform
# Every command each identity may run with the namespace default IAM role.
data "redshift_assumerole_grants" "default_role" {
  iam_role_arn = "DEFAULT"
}

output "default_role_commands" {
  value = { for grant in data.redshift_assumerole_grants.default_role.assumerole_grants : "${grant.grantee_type} ${grant.grantee}" => grant.privileges }
}
```

## Read Behavior

The catalog names the namespace default role `default-aws-iam-role` and a grant `ON ALL` `default`; the listing
reports them as `DEFAULT` and `ALL`, and translates an `iam_role_arn` filter the same way. The view also repeats a
grantee's `ON ALL` commands under every IAM role that another grant names, so those elements show access the `ALL`
element supplies. `PUBLIC` holds every command `ON ALL` until it is revoked.

The view shows only entries visible to the provider's identity (superusers and users with `ACCESS SYSTEM TABLE` see
all). `id` is the listing's provider-relative JSON identity: the configured filters.
