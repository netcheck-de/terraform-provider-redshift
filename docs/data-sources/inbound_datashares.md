# redshift_inbound_datashares (Data Source)

Lists the inbound datashares of the provider's namespace: shares that a producer granted to it, with the database
created from each. See AWS [SVV_DATASHARES](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_DATASHARES.html).
No resource manages an inbound share; `redshift_database` with `datashare_arn` creates a database from one.

## Example Usage

```terraform
data "redshift_inbound_datashares" "all" {}

output "unconsumed_datashares" {
  value = [for share in data.redshift_inbound_datashares.all.inbound_datashares : share.name if share.consumer_database == null]
}
```

## Read Behavior

`inbound_datashares` is empty when nothing matches; it is ordered by name. `producer_account` and `producer_namespace`
identify the producer. `consumer_database` is null until a database is created from the share.

`id` (String, computed) is the listing's provider-relative JSON identity containing the configured filters.

Superusers, share owners, and users with `ALTER` or `USAGE` on a share see it; other users see no shares. Only read-only
SQL is executed.
