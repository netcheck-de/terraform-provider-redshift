# redshift_datashare_privileges (Data Source)

Lists the explicit `ALTER` and `SHARE` permissions that users, roles, groups, and `PUBLIC` hold on the outbound
datashares of the provider's namespace, one element per share and grantee, as `redshift_datashare_privilege` manages
them. See AWS
[SVV_DATASHARE_PRIVILEGES](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_DATASHARE_PRIVILEGES.html).

## Example Usage

```terraform
data "redshift_datashare_privileges" "reporting" {
  datashare_name = "reporting"
}

output "share_administrators" {
  value = { for item in data.redshift_datashare_privileges.reporting.datashare_privileges : "${item.grantee_type}:${item.grantee}" => item.privileges }
}
```


## Read Behavior

`datashare_privileges` is empty when nothing matches; it is ordered by share, grantee type, and grantee. One query in
the provider database covers the shares of every producer database, each reported with its `database_name`. `PUBLIC`
is reported with `grantee = "public"`; the `grantee` filter `public` selects it. Permissions held with grant option are
reported like any other.

`id` (String, computed) is the listing's provider-relative JSON identity containing the configured filters.

Superusers and users with the `ACCESS SYSTEM TABLE` permission see every grant; other users see only identities they
can access or own. Only read-only SQL is executed.
