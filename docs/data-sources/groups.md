# redshift_groups (Data Source)

Lists every SQL user group with its ID and member users. See AWS
[Groups](https://docs.aws.amazon.com/redshift/latest/dg/r_Groups.html).

## Example Usage

```terraform
data "redshift_groups" "all" {}

output "group_members" {
  value = { for group in data.redshift_groups.all.groups : group.name => group.members }
}
```

## Read Behavior

Items are ordered by name; `members` is empty for a group without members. Every user can read `pg_group` and
`pg_user`, so every group is listed. Values match what `redshift_group` reports for each group. `id` identifies the
listing within the configured warehouse.
