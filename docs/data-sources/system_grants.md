# redshift_system_grants (Data Source)

Lists the system permissions granted directly to roles, one element per role, without taking ownership. Each element
matches the identity and privileges of one `redshift_system_grant`. See AWS
[SVV_SYSTEM_PRIVILEGES](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_SYSTEM_PRIVILEGES.html).

## Example Usage

```terraform
data "redshift_system_grants" "all" {}

output "system_grants" {
  value = { for grant in data.redshift_system_grants.all.system_grants : grant.role => grant.privileges }
}
```

## Read Behavior

System permissions are warehouse-wide, so the listing runs in the provider database. Permissions granted to users
are left out, because only roles receive them through `redshift_system_grant`. The view shows only identities visible
to the provider's identity (superusers and users with `ACCESS SYSTEM TABLE` see all). `id` is the listing's
provider-relative JSON identity: the configured filters.
