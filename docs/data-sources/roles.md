# redshift_roles (Data Source)

Lists every database role with its owner and identity-provider external ID, including the built-in `sys:` roles
and roles of identity providers. See AWS [SVV_ROLES](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_ROLES.html).

## Example Usage

```terraform
data "redshift_roles" "all" {}

output "custom_roles" {
  value = [for role in data.redshift_roles.all.roles : role.name if !startswith(role.name, "sys:")]
}
```

## Read Behavior

Items are ordered by name. `SVV_ROLES` is visible to all users, so every role is listed. Values match what
`redshift_role` reports for each role. `id` identifies the listing within the configured warehouse.
