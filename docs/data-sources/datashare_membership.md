# redshift_datashare_membership (Data Source)

Observes whether all currently visible tables/views or SQL function overloads in a producer schema have visible share
memberships. Does not adopt members or enforce exclusive ownership, and does not require a SQL superuser. `exists`
indicates that the schema membership is visible; `all` indicates coverage of the visible source set only. An empty
visible source set is covered; a schema membership that is absent or invisible has `exists = false, all = false`.
Restricted visibility can therefore yield `all = true` without proving that every actual source object is shared.

## Catalog Query

```sql
SELECT ... FROM svv_datashare_objects WHERE share_type = 'OUTBOUND' AND share_name = '...';
SELECT ... FROM svv_all_tables WHERE database_name = '...' AND schema_name = '...';
SELECT ... FROM pg_proc_info JOIN pg_namespace ... JOIN pg_language ... WHERE nspname = '...';
```

## Example Usage

```terraform
data "redshift_datashare_membership" "functions" {
  database  = "analytics"
  datashare = "reporting"
  schema    = "reporting"
  kind      = "FUNCTIONS"
}
```

## Schema

### Required

- `database` (String) Local producer database.
- `datashare` (String) Producer datashare name.
- `kind` (String) TABLES observes visible tables and views; FUNCTIONS observes visible SQL UDF overloads.
- `schema` (String) Producer schema whose visible membership is observed. Periods in schema or visible source member names are unsupported because the catalog does not quote qualification. Future-object inclusion may be enabled or disabled.

### Read-Only

- `all` (Boolean) Whether every currently visible source object of the selected kind has a visible share membership. True for an empty visible source set; false when the schema membership is not visible. This observation does not prove complete coverage under restricted catalog visibility and does not require a SQL superuser.
- `exists` (Boolean) Whether this explicit relationship exists. False also covers missing parents.
- `id` (String) JSON identity of the observed object, using the same format as the paired resource. Null for a missing relationship.
