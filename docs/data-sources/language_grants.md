# redshift_language_grants (Data Source)

Lists explicit `USAGE` grants on the `SQL` and `PLPGSQL` languages of one local database, one element per language
and grantee, without taking ownership. Each element matches the identity and privileges of one
`redshift_language_grant`. See AWS
[SVV_LANGUAGE_PRIVILEGES](https://docs.aws.amazon.com/redshift/latest/dg/r_SVV_LANUGAGE_PRIVILEGES.html).

## Example Usage

```terraform
data "redshift_language_grants" "analytics" {
  database_name = "analytics"
}

output "language_grants" {
  value = [for grant in data.redshift_language_grants.analytics.language_grants : "${grant.grantee_type} ${grant.grantee}: ${grant.language_name}"]
}
```

-- List explicit SQL and PLPGSQL privileges in the selected database.

## Read Behavior

The view reports only the current database, so the listing runs in `database_name`. It lists only explicit grants:
`PUBLIC` holds `USAGE` on both languages by default, which may have no element until it is revoked. Other languages
are left out. The view shows only grants visible to the provider's identity (superusers and users with
`ACCESS SYSTEM TABLE` see all). `id` is the listing's provider-relative JSON identity: the target `database_name` and
the configured filters.
