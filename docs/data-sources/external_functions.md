# redshift_external_functions (Data Source)

Lists the Lambda user-defined functions (`LANGUAGE EXFUNC`) of one database, one element per overload, with the values
of `redshift_external_function` that the catalog reports. See AWS
[PG_PROC_INFO](https://docs.aws.amazon.com/redshift/latest/dg/r_PG_PROC_INFO.html).

## Example Usage

```terraform
data "redshift_external_functions" "serving" {
  database = "warehouse"
  schema   = "serving"
}

output "lambda_udfs" {
  value = [for function in data.redshift_external_functions.serving.external_functions : "${function.name}(${join(", ", function.arguments)}) -> ${function.return_type}"]
}
```

## SQL Statements

Simplified SQL used by the provider to read this data source.

```sql
-- List Lambda UDF overloads matching the configured filters from pg_proc_info.
SELECT ... FROM pg_proc_info WHERE prokind = 'f' AND lanname = 'exfunc' AND nspname = '...' AND proname = '...';
```

## Read Behavior

The listing reads the catalog of the selected database, ordered by schema, name, and argument types. No catalog view
reports a function's Lambda function, IAM role, retry timeout, or batch limits, so the elements carry only its
signature, return type, volatility, and owner. SQL UDFs are listed by `redshift_functions`. An empty
`external_functions` list means that nothing matches; a missing database or a catalog failure is an error. `id`
contains the database and configured filters.
