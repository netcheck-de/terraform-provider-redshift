# redshift_group_memberships (Data Source)

Lists explicit user-to-group memberships, optionally of one group or one user. See AWS
[ALTER GROUP](https://docs.aws.amazon.com/redshift/latest/dg/r_ALTER_GROUP.html).

## Example Usage

```terraform
data "redshift_group_memberships" "readers" {
  group = "report_readers"
}

output "report_readers" {
  value = [for membership in data.redshift_group_memberships.readers.group_memberships : membership.user]
}
```

## SQL Statements

## Read Behavior

Items are ordered by group and user. Every user can read `pg_group` and `pg_user`, so every membership is
listed. Filters match names exactly. `id` contains the configured filters within the warehouse.
